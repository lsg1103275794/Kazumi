# 网盘媒体（WebDAV）使用指南

Kazumi 支持将你的网盘（通过 WebDAV 协议）作为番剧片源：既可以手动浏览网盘里的视频文件直接播放，也可以在番剧详情页的「播放来源」中自动匹配网盘里的同名文件夹。

## 功能入口

- **网盘媒体**：设置 → 资源 → 网盘媒体，按目录浏览网盘中的视频文件并播放。
- **来源联动**：打开任意番剧详情页的「播放来源」，若网盘中存在与番剧同名的文件夹，会自动出现「网盘」来源，点开即可像正常选集一样播放。

## 第一步：准备 WebDAV 服务

网盘本身大多不直接提供 WebDAV，推荐使用 [AList](https://alist.nn.ci/) 做桥接：

1. 部署 AList（Docker 或 Windows 二进制均可）。
2. 在 AList 后台「存储」中添加你的网盘驱动（如夸克、阿里云盘、115 等）。
3. 确认 AList 的 WebDAV 已开启，地址形如 `http://127.0.0.1:5244/dav/`。

> 也支持任何标准 WebDAV 服务器（坚果云、InfiniCloud、自建服务等）。

## 第二步：在 Kazumi 中配置

1. 打开 设置 → 应用 → 同步设置 → 连接 WebDAV（同步服务器）。
2. 填写：
   - **服务器地址**：例如 `http://127.0.0.1:5244/dav/`
   - **用户名 / 密码**：WebDAV 服务的账号
3. 点击「保存并测试」，提示「连接成功」即可。

> 该配置同时服务于：多设备同步、网盘媒体浏览、来源联动。

## 第三步：使用

### 浏览播放

设置 → 资源 → 网盘媒体，逐级进入文件夹，点击视频文件即可在线播放（流式加载，无需下载）。

### 来源联动

打开番剧详情 → 播放来源，若网盘中存在与番剧同名的文件夹（默认向下扫描 3 层目录），会显示「网盘」来源：

```
播放来源
├── 7sefun        （规则插件）
├── DM84          （规则插件）
└── 📁 网盘        （命中: 凡人修仙传）
      └── 01.mp4 / 02.mp4 / ...
```

点击匹配的文件夹即可选择选集播放。

## 推荐的网盘目录结构

来源联动按「文件夹名」匹配番剧名称，建议按番剧名建立文件夹，剧集文件平铺其中：

```
/
└── 电视/
    └── 凡人修仙传/
        ├── 01.mp4
        ├── 02.mp4
        └── ...
```

支持的常见视频格式：mp4 / mkv / avi / mov / flv / wmv / webm / ts / m2ts / mpg / rmvb 等。

## 常见问题

- **连接失败**：检查地址是否以 `/dav/` 结尾（AList）、账号密码是否正确、AList 是否在运行。
- **来源联动没有出现「网盘」**：确认已配置 WebDAV；番剧文件夹需在根目录向下的 3 层以内，且文件夹名包含番剧名。
- **播放卡顿**：流式播放依赖网络带宽，大文件（4K 原盘）建议使用本地 AList 或提升带宽。
- **Cookie 类网盘失效**：AList 侧的网盘凭证过期会导致列目录失败，重新在 AList 后台刷新凭证即可。
